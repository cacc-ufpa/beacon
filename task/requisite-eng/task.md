# Concepção de projeto com engenharia de requisitos

*Em: Engenharia de Software I - Sandro Ronaldo Bezerra - 2026.*

A atividade 1 consiste em ensaiar algum sistema de interesse a ser desenvolvido, descrevendo:

 - Problema.
 - Afetado.
 - Impacto (causa).
 - Solução.
 - Justificativa.
 - Objetivo.
 - Escopo.

A atividade 2 consiste em classificar os requisitos a seguir para um sistema de venda de ingressos de cinema:

 - O sistema deve solicitar tanto ao  gerente quanto ao cliente em qual filial deseja se conectar, no caso do gerente podendo ter acesso à versão restrita.
 - O sistema deve ter uma interface leve (abrir em no máximo 4 segundos e com pouca animação/imagens).
 - O sistema deve disponibilizar informações de horários, salas e sinopses dos filmes em cartaz e os que estrearão na semana seguinte.
 - O sisstema deve conter um sistema de cadastros de usuários.Somente usuários cadastrados podem comprar ingressos.
