== Autômatos (Reginaldo Cordeiro)
:stem: asciimath

Autômatos com pilha.

Transição de conclusão baseada em estado final para conclusão baseada em esvaziamento de pilha.

Algoritmo CYK para checar se uma cadeia pertençe à gramática na forma normal de Chomsky.


Exemplo:

[stem]
++++
M = (", Sigma, Gamma, delta, Z_0, F)
delta: Q times (Sigma uu {epsilon} times Gamma) -> 2^(Q times Gamma^ast)
++++

[d2]
----
direction: right
q0: { shape: circle }
q0 -> q0: |latex
	\displaylines {
	\epsilon, Z_0: \epsilon \\
	b, A_0: \epsilon \\
	\epsilon, X_0: \epsilon \\
	a, X_0: X_0 A_0 \\
	a, Z_0: X_0 A_0 Z_0
	}
|
----
