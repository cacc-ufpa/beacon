# Descrição de requisitos

Atividade 1: descrever os requisitos do sistema ensaiado na Tarefa 3, que foram elicitados na Tarefa 4, usando a forma sentencial padrão. No mínimo 20 requisitos, com pelo menos 10.

Forma sentencial padrão:

```
O sistema deve + [verbo + objeto | frase verbal] + [complemento de agente | nulo] + [condições | nulo]
```

Atividade 2: especifique 5 requisitos usando o padrão:

 - Identificador.
 - Nome e breve descrição.
 - Ator(es).
 - Prioridade.
 - Requisitos não-funcionais associados.
 - Pré-condições.
 - Pós-condições.
 - Fluxo de eventos principal.
 - Fluxos secundários: alternativos e de exceção (4 fluxos diferentes para cada um dos 5 requisitos).
