# Elicitação de requisitos

Atividade 1: definir no mínimo 20 perguntas que permitam elicitar requisitos referentes ao sistema ensaiado na tarefa anterior.

Atividade 2: escolher um método de elicitação de requisitos para executar com base nas perguntas definidas.

Atividade 3: reescreva os seguintes requisitos para remover ambiguidades:

 - O sistema bibliotecário deve ser fácil de usar.
 - O sistema deve fornecer um serviço confiável a todas as classes de usuários.
 - O sistema deve permitir uma resposta rápida a todos os pedidos de informação.
