# Abreviações

Abreviações de nomes de matérias e de professores para serem usadas quando consição é desejável:

 - Nomes de arquivos.
 - Mensagens de commit.

Em especial, servem para encurtar a identificação de uma turma:

```
ano-semestre-materia-professor
```
